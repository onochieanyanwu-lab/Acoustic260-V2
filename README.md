# Acoustic 260 V2 (VST3)

Separate plugin from V1 (own name "Acoustic 260 V2", own plugin ID), so both can be loaded side by side.

Changes from V1: cascaded preamp stages that saturate progressively, rebuilt two-stage fuzz with an
Attack network (far less compressed), power amp with softer knee + rail sag + crossover grit.

All files are in one flat folder. Workflow file goes in `.github/workflows/build.yml`.
